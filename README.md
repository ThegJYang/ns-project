# ns-project

Research repo for the S.-T. Yau High School Science Award project *Numerical Semigroups, Formalized*: write-up, GAP cross-checks, and the literature audit table.

The Lean 4 / Mathlib library (must build, CI-green) lives in the companion repo: [ns-lean](https://github.com/ThegJYang/ns-lean).

## Contents

- `results-table.md` — audit results: paper → claim → verdict
- `discrepancies.md` — confirmed errors in published papers, cross-checked by Lean and GAP
- `todo.md` — project checklist and known weaknesses
- `NumSemigroups_MVP.pptx` — MVP status presentation
